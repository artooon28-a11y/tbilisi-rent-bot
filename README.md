# Аренда в Тбилиси — бот для Telegram-канала

Раз в 3 часа GitHub Actions собирает свежие объявления об аренде квартир в Тбилиси с ss.ge
(помесячно и посуточно) и публикует в канал одно лучшее объявление за этот период (сначала «ниже рынка», затем рядом с метро, с мебелью, с большим числом фото): фото, цена, район, метро, хэштеги и две кнопки —
«Открыть объявление» и ваша кнопка eSIM.

## Настройка (один раз)

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → получите токен.
2. **Канал.** Добавьте бота администратором канала с правом «Публикация сообщений».
3. **Секреты.** В репозитории: *Settings → Secrets and variables → Actions → New repository secret*:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `CHANNEL_ID` — `@имя_канала` (для приватного канала — числовой ID вида `-100…`)
4. **Ссылка на eSIM.** Там же, вкладка *Variables* → `ESIM_URL` (ссылка на ваш бот/сайт).
   Либо впишите её в `esim_url` в `config.json`.
5. **Запуск.** Вкладка *Actions → post-listings → Run workflow*. Дальше всё идёт само.

Пока секреты не заданы, бот работает в режиме предпросмотра: ничего не публикует и
сохраняет примеры постов в `preview.md`.

## Настройки в `config.json`

| Поле | Что делает |
|---|---|
| `sections` | какие разделы собирать: помесячно (`qiravdeba`) и посуточно (`qiravdeba-dghiurad`), сколько страниц |
| `max_age_hours` | публиковать только объявления, созданные не раньше чем N часов назад |
| `max_posts_per_run` | сколько постов за один запуск (запуск раз в 3 часа; расписание — строка `cron` в `.github/workflows/post.yml`) |
| `price_usd_month`, `price_usd_day` | ценовые рамки в долларах |
| `require_photo` | пропускать объявления без фото |
| `photos_per_post` | сколько фото в альбоме (до 10); текст с кнопками идёт следующим сообщением |
| `esim_button_text`, `esim_url` | текст и ссылка второй кнопки |
| `promo_line`, `contact_line` | строка в конце каждого поста (например, промокод), пусто — не выводится |

## Как это устроено

- `bot.py` — сбор, фильтры, форматирование, отправка.
- `state/posted.json` — что уже опубликовано (чтобы не было дублей) и статистика цен за м²
  по районам для метки «🔥 ниже рынка». Бот сам коммитит этот файл после каждого запуска.
- При первом запуске бот публикует одно объявление, остальные помечает как уже виденные.

Описания объявлений не копируются: в посте только параметры, фото и ссылка на источник.
